# geojson-to-wkt

PWA made with Nuxt, Nuxt UI, Pinia and MapLibre (via
[`@indoorequal/vue-maplibre-gl`](https://github.com/indoorequal/vue-maplibre-gl))
to convert between GeoJSON and WKT formats. Basemaps by
[OpenFreeMap](https://openfreemap.org).

![Preview](https://i.imgur.com/OuTbA5Z.png)

## Project setup

```bash
pnpm install
```

### Development server

```bash
pnpm dev
```

### Static build

```bash
pnpm generate
```

### Checks

```bash
pnpm lint
pnpm typecheck
```
